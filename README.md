# Frame 2.1.1 · 影片剪輯（附螢幕錄影）

Frame 是在瀏覽器裡執行的影片剪輯工具，只有一個 HTML 檔。不用安裝、不用部署，也不需要 Node.js、Python 或 FFmpeg。素材、專案和匯出都在你自己的電腦和瀏覽器處理，不會上傳。

## 開始使用

1. 下載 `FrameRecorder.html`（和 `Start.cmd`）。也可以按綠色的 **Code → Download ZIP** 下載整包。
2. 雙擊 `Start.cmd`，或用桌面版 Edge／Chrome 打開 `FrameRecorder.html`。
3. 按「匯入」加入影片、圖片或音訊，就能開始剪輯。

## 能做什麼

- 修剪、分割、拖曳排序、在片段上拖曳選範圍（保留／刪除／切成獨立片段）
- 速度（0.25～16 倍、漸變）、畫面調整、Ken Burns 推拉
- 字幕、疊圖／子母畫面、旁白、轉場、配樂
- 錄製螢幕、視窗或分頁，錄完自動接在成片最後
- Ctrl+Z 復原、自動保存專案

## 匯出

- **快速匯出**：產生 MP4，可以把分頁切到背景。
- **相容匯出**：通常產生 WebM。要邊播邊錄，所以匯出時這個分頁要一直看得到，切走會取消。
- 匯出後按「下載」，檔案會存到瀏覽器的下載資料夾。**沒按下載就關掉，影片就沒了。**

## 要注意

- 專案存在目前的瀏覽器裡。清除網站資料、換瀏覽器、用無痕模式，或把 HTML 檔搬到別的位置，都可能讀不到舊專案。重要的影片請匯出下載。
- 「專案素材」目前還不能單獨刪一支；按「新專案」會清掉全部。
- 這一版已在 Edge（headless）通過瀏覽器自動測試和真實滑鼠／鍵盤／觸控測試。真實觸控螢幕、Windows 顯示比例、Narrator 還沒有實機驗證。
